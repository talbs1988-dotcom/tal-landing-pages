# דפי נחיתה שעובדים בשבילך

הסיסטם של טל בשור לבניית דף נחיתה מקצועי בעברית, שלב אחרי שלב, עם Claude Code. מהאפיון ועד ליד שמגיע ל-CRM.

## התקנה

בתוך Claude Code, שורה אחת בכל פעם:

    /plugin marketplace add talbs1988-dotcom/tal-landing-pages
    /plugin install tal-landing-pages@tal-landing-pages

ואז סוגרים את Claude Code ופותחים מחדש.

## מתחילים

    /page-start

ומשם, בכל רגע: `/page` — איפה אני ומה עכשיו.
