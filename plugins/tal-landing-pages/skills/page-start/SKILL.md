# שלב 0 — הכנה

קודם לקרוא את החוקה ולעבוד לפיה: `<Base directory של הסקיל הזה>/../../references/stage-contract.md`.

## נתיבים ושמות בפקודות

- `$SCRIPTS` בקובץ הזה הוא **קיצור בלבד**, לא משתנה של הטרמינל. משתנים לא עוברים מפקודה לפקודה, אז בכל פקודה כותבים את הנתיב המלא: `<Base directory של הסקיל הזה>/../../scripts/scaffold.mjs` (או `status.mjs`).
- כל שם או הערה בפקודה עוטפים בגרש בודד: `'דנה בע"מ'`.
- שם שיש בו גרש (') — לכתוב אותו כ-`'\''`. למשל `צ'יפס` נכתב `'צ'\''יפס'`.

## איך פונים למשתתף

עד שיודעים — מדברים ברבים ("תנו", "כתבו"). אחרי שהמשתתף ענה, או אם זה כבר כתוב בשורה "פנייה לבעל העסק" ב-CLAUDE.md — פונים לפי זה.

השלב הזה שונה מהשאר בדבר אחד: הוא זה שיוצר את המצב, אז צעדים 1–2 של החוקה נעשים כאן ככה:

## א. איפה אנחנו

1. לחפש תיקיית עסק, בתיקייה הנוכחית או מעליה: `node '$SCRIPTS/scaffold.mjs' find-root '<התיקייה הנוכחית>'`.
2. **נמצאה** (הפלט הוא נתיב) → זו תיקיית העסק, גם אם היא מעל התיקייה הנוכחית. לומר "מצאתי את התיקייה של <שם העסק מה-CLAUDE.md>: <הנתיב>" ולדלג ל-ג. **אף פעם לא ליצור תיקיית עסק חדשה בתוכה.**
3. **לא נמצאה** ("לא נמצאה תיקיית עסק") → לשאול שאלה אחת: "איך קוראים לעסק?" (דוגמה: "הסטודיו של דנה").
   - התיקייה הנוכחית היא תיקיית הבית, שולחן העבודה, מסמכים או הורדות (`~`, `~/Desktop`, `~/Documents`, `~/Downloads`) → **אף פעם לא ליצור בה ישירות.** תמיד להציע תיקייה חדשה בשם העסק בתוכה, ולחכות לאישור.
   - אחרת, אם התיקייה הנוכחית ריקה, או שהמשתתף אומר שזו התיקייה של העסק — ליצור בה.
   - אחרת — להציע ליצור תיקייה חדשה בשם העסק בתוך התיקייה הנוכחית, ולחכות לאישור.
   - ליצור: `node '$SCRIPTS/scaffold.mjs' business '<תיקיית העסק>' '<שם העסק>'`.
   - אם כבר היה שם CLAUDE.md — הסקריפט משאיר את מה שכתוב בו ומוסיף את החלקים של הסיסטם מתחת. לומר את זה למשתתף במשפט אחד.
4. רק אם תיקיית העסק נוצרה עכשיו — עוד שאלה, בהודעה נפרדת: "איך לפנות אליך — בלשון זכר, נקבה או רבים?". לכתוב את התשובה ב-CLAUDE.md של העסק, בשורה `- פנייה לבעל העסק:`.

## ב. להסביר את הארכיטקטורה (פעם ראשונה בלבד)

אם תיקיית העסק נוצרה עכשיו — להראות את העץ, עם שם התיקייה כמו שהוא בדיסק, ולהסביר בשלוש שורות:

- **CLAUDE.md** — הזיכרון של העסק. כל פקודה קוראת אותו.
- **brand/ ו-legal/** — ממלאים פעם אחת, משמשים את כל הדפים.
- **landing-pages/** — תיקייה לכל דף, עם מקום קבוע לכל שלב.

## ג. דף חדש

1. שם הדף: מהארגומנט אם נשלח. אחרת לשאול: "על מה הדף? תנו לו שם קצר" (דוגמה: "סדנת גיוס", "מדריך חינמי").
2. ליצור: `node '$SCRIPTS/scaffold.mjs' page '<תיקיית העסק>' '<שם הדף>'`. הפלט הוא הנתיב של תיקיית הדף.
3. להראות את התיקיות שנוצרו ומה נכנס לכל אחת, במשפט אחד לכל תיקייה.

## ד. כלים

קודם הגרסה של קלוד: `claude --version`. אם הפקודה נכשלה או שהגרסה נראית ישנה — להציע `claude update` (המשתתף מאשר).

אחר כך לבדוק מה כבר מותקן ולהתקין רק את מה שחסר. לכל כלי — משפט אחד למה הוא שם:

| כלי         | למה                                            | בדיקה                                         | התקנה                                                                                                             |
| ----------- | ---------------------------------------------- | --------------------------------------------- | ----------------------------------------------------------------------------------------------------------------- |
| Playwright  | קלוד פותח את הדף בדפדפן אמיתי ובודק אותו בעצמו | `claude mcp get playwright` מצליח             | `claude mcp add -s user playwright -- npx @playwright/mcp@latest`                                                 |
| taste-skill | מזהה עיצוב שנראה כמו תבנית                     | `~/.claude/skills/design-taste-frontend` קיים | `npx --yes skills add https://github.com/Leonxlnx/taste-skill --skill design-taste-frontend -g -a claude-code -y` |
| impeccable  | מוצא טעויות עיצוב בדף החי                      | `~/.claude/skills/impeccable` קיים            | `npx --yes skills add pbakaus/impeccable --skill impeccable -g -a claude-code -y`                                 |
| סקילי תנועה | אנימציות עדינות ונכונות                        | `~/.claude/skills/emil-design-eng` קיים       | `npx --yes skills add emilkowalski/skills --skill emil-design-eng -g -a claude-code -y`                           |

- כל התקנה מורידה קוד חיצוני — המשתתף מאשר כל אחת.
- התקנה שנכשלה: לא לעצור. לרשום ולהמשיך. השלבים הבאים יודעים לעבוד בלעדיה ויגידו מה לא נבדק.

## ה. סיום

1. `node '$SCRIPTS/status.mjs' set '<תיקיית הדף>' start done 'התיקייה מוכנה. הותקנו: <שמות הכלים שהותקנו, או: כלום>'`.
2. **תיקיית העסק היא לא התיקייה שבה קלוד נפתח** → תמיד (גם אם לא הותקן כלום) לומר בדיוק כך, עם הנתיב המלא:
   > **עכשיו סוגרים את קלוד ופותחים אותו מחדש בתוך תיקיית העסק:** `<נתיב מלא>`
   >
   > בטרמינל: `cd '<נתיב מלא>' && claude`
   >
   > באפליקציה: כשפותחים שיחה חדשה, בוחרים את התיקייה הזו.
   >
   > אחרי שנפתח — מקלידים `/page` ונמשיך משם.
3. **זו אותה תיקייה, והותקן משהו** → לומר: "**עכשיו סוגרים את קלוד ופותחים מחדש, באותה תיקייה.** קלוד טוען כלים חדשים רק כשהוא עולה. אחרי שנפתח — מקלידים `/page` ונמשיך משם."
4. **זו אותה תיקייה, ולא הותקן כלום** → לומר: "הכול מוכן. הפקודה הבאה: `/page-brief`".
