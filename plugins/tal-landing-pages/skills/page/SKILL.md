# איפה אני ומה עכשיו

## נתיבים ושמות בפקודות

- `$SCRIPTS` = `<Base directory של הסקיל הזה>/../../scripts` (התיקייה). זה **קיצור בלבד**, לא משתנה של הטרמינל. משתנים לא עוברים מפקודה לפקודה, אז בכל פקודה כותבים את הנתיב המלא, למשל: `node '<Base directory של הסקיל הזה>/../../scripts/status.mjs' …`.
- כל נתיב, שם או הערה בפקודה עוטפים בגרש בודד: `'דנה בע"מ'`.
- נתיב או שם שיש בו גרש (') — לכתוב אותו כ-`'\''`. למשל `צ'יפס` נכתב `'צ'\''יפס'`.

## הודעת "פותחים מחדש"

> **עכשיו סוגרים את קלוד ופותחים אותו מחדש בתוך תיקיית העסק:** `<נתיב מלא>`
>
> בטרמינל במק: `cd '<נתיב מלא>' && claude`
>
> בטרמינל בווינדוס (PowerShell): `cd '<נתיב מלא>'; claude`
>
> באפליקציה: כשפותחים שיחה חדשה, בוחרים את התיקייה הזו.
>
> אחרי שנפתח — מקלידים `/page` ונמשיך משם.

## איך פונים למשתתף

לפי השורה "פנייה לבעל העסק" ב-CLAUDE.md. לא מולאה → ברבים. הטבלה למטה כתובה ברבים, ומתאימים אותה לפנייה כשמציגים אותה.

## הצעדים

1. **למצוא את תיקיית העסק** — בתיקייה הנוכחית או מעליה: `node '$SCRIPTS/scaffold.mjs' find-root '<התיקייה הנוכחית>'`. הפלט הוא הנתיב של תיקיית העסק.
   - לא נמצאה ("לא נמצאה תיקיית עסק") → לחפש רמה אחת מתחת: `node '$SCRIPTS/scaffold.mjs' find-below '<התיקייה הנוכחית>'`. הפלט הוא רשימה של נתיבים.
     - נמצאה אחת → לומר "מצאתי את תיקיית העסק ב-<הנתיב>", לתת את הודעת "פותחים מחדש" עם הנתיב הזה, ולעצור.
     - נמצאו כמה → להראות את הרשימה ולשאול באיזו עובדים. אחרי התשובה — הודעת "פותחים מחדש" עם הנתיב שנבחר, ולעצור.
     - הרשימה ריקה → "עוד לא התחלנו. מקלידים `/page-start` ונבנה את התיקייה." ולעצור.
2. **למצוא את הדפים** — `node '$SCRIPTS/status.mjs' list '<תיקיית העסק>'`. הפלט: רשימה של דפים, לכל אחד `dir` (הנתיב), `folder`, `pageName` ו-`next` (השלב הבא, או `null` אם הכול אושר). תיקיות בלי קובץ מצב (גיבוי, ישן וכו') לא מופיעות ולא נחשבות.
   - דף שיש לו `error` → להציג אותו כ"דף עם קובץ מצב פגום: <folder>" ולא להמשיך איתו בלי שהמשתתף מבקש לבדוק אותו.
   - התיקייה הנוכחית נמצאת בתוך אחד הדפים (`landing-pages/NN-x/...`) → לבחור את הדף הזה לבד ולומר: "אנחנו בתוך הדף <pageName>, ממשיכים איתו."
   - אין דפים → "אין עדיין דף. מקלידים `/page-start`."
   - דף אחד → הוא.
   - כמה דפים → להראות רשימה קצרה (שם + השלב הבא של כל אחד) ולשאול על איזה ממשיכים.
3. **להראות את המצב** — `node '$SCRIPTS/status.mjs' show '<תיקיית הדף>'` ולהציג את הטבלה כמו שהיא.
4. **לוודא שהכלים נטענו** — אם ההערה של שלב 0 אומרת שהותקנו כלים, לבדוק מהר רק אותם:
   - Playwright: `claude mcp get playwright` מצליח. אם הפקודה `claude` לא נמצאה (באפליקציה) — לדלג על הבדיקה הזו.
   - סקילים: התיקיות קיימות ב-`~/.claude/skills/` (`design-taste-frontend`, `impeccable`, `emil-design-eng`).
   - מה שחסר — שורה אחת: מה חסר ומה זה אומר (למשל: "Playwright לא נטען, אז בשלב הבדיקה קלוד לא יפתח את הדף בדפדפן בעצמו"). לא לעצור בגלל זה.
5. **כל השלבים אושרו** (`next` הוא `null`, ו-`show` מדפיס "כל השלבים אושרו") → לא מציעים שלב. אומרים בדיוק את זה, ועוצרים:

   > הדף באוויר ומחובר. שיניתם משהו בדף (למשל טקסט במצב עריכה)? השינוי נשמר רק במחשב. כדי שיופיע בדף שבאוויר, מקלידים `/page-check` ואחר כך `/page-live`. דף חדש: `/page-start`.

6. **להגיד מה עכשיו**, בשני משפטים:
   - מה השלב הבא עושה, במשפט אחד פשוט.
   - מה כדאי להכין לפניו (לפי הטבלה למטה).
7. **לשאול:**
   - השלב הבא עוד לא התחיל → "להתחיל את <השלב>?"
   - השלב הבא כבר "בעבודה" → "להמשיך את <השלב> מאיפה שעצרנו?" ולהגיד במשפט איפה עצרנו, לפי ההערה שלו בטבלה.
   - אם כן — להפעיל את הסקיל של השלב. שלב "בעבודה" ממשיך מהנקודה שבהערה, לא מההתחלה.
