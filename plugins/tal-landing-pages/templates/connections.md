## משתני סביבה ב-Vercel

אלה ההגדרות שהאתר קורא ב-Vercel. כאן רק השמות ואם הם מוגדרים. הערכים עצמם נמצאים רק ב-Vercel (הפרויקט ← Settings ← Environment Variables).

| משתנה                                     | מה זה, במילים                                         | מוגדר ב-Production |
| ----------------------------------------- | ----------------------------------------------------- | ------------------ |
| `BLOB_STORE_ID` / `BLOB_READ_WRITE_TOKEN` | החיבור לאחסון של הגיבוי. נוסף לבד כשיוצרים את האחסון  | [למלא]             |
| `WEBHOOK_URL`                             | הכתובת ב-Make שמקבלת כל ליד (סוד)                     | [למלא]             |
| `ALERT_WEBHOOK_URL`                       | הכתובת שמקבלת התראה כש-Make לא קיבל ליד (סוד, רשות)   | [למלא]             |
| `NEXT_PUBLIC_META_PIXEL_ID`               | מזהה הפיקסל, לדפדפן                                   | [למלא]             |
| `META_PIXEL_ID`                           | אותו מזהה, לדיווח מהשרת                               | [למלא]             |
| `META_CAPI_TOKEN`                         | המפתח לדיווח מהשרת למטא (סוד)                         | [למלא]             |
| `META_CAPI_TEST_CODE`                     | קוד בדיקה זמני. צריך להיות **לא מוגדר** אחרי הבדיקה   | [למלא]             |

## ליד שלא הגיע

1. ההתראה (אם הוגדרה) אומרת את מזהה הליד.
2. הליד נמצא בגיבוי: Vercel ← הפרויקט ← Storage ← ה-store ← Browser ← `leads/` ← תיקיית התאריך ← `<מזהה>.json`.
3. שליחה מחדש ל-Make: `site/TEMPLATE.md`, "ליד שלא הגיע ל-Make". שולחים רק את מה שלא הגיע. הפקודה מקבלת את כתובת הוובהוק, ולכן בעל העסק מריץ אותה בטרמינל שלו, לא קלוד.
