# תנועה בדף

הקובץ הזה לקלוד בתת־שלב 3ה (ליטוש) של `/page-design`. דף נחיתה לא צריך להרשים בתנועה. תנועה טובה בדף כזה כמעט לא מורגשת: היא עוזרת להבין מה קרה, ונעלמת.

## 1. מתי זז משהו

רק כשיש לתנועה תפקיד. אלה המקרים שמותרים:

| מקרה                             | התפקיד                                         |
| -------------------------------- | ---------------------------------------------- |
| סקשן נכנס בגלילה (מתחת לקיפול)   | מסמן "הגעתם לחלק חדש"                          |
| משוב על כפתור (מעבר עכבר, לחיצה) | מראה שהכפתור חי ושהלחיצה נקלטה                 |
| מצבי הטופס                       | "שולח...", הודעת שגיאה שמופיעה, דף התודה שנכנס |
| פתיחה של שאלה נפוצה              | מראה מאיפה הגיעה התשובה                        |

כל מה שלא ברשימה, לא זז. למשל: רקע שזז בגלילה (parallax), טקסט שמוקלד אות אחרי אות, מספרים שרצים עד הערך שלהם, קרוסלת המלצות שמתחלפת לבד, אפקטים שעוקבים אחרי העכבר, אלמנט שמהבהב כדי למשוך תשומת לב.

## 2. איך זז

| מה                            | משך       |
| ----------------------------- | --------- |
| מעבר עכבר ולחיצה על כפתור     | 120–160ms |
| שינוי מצב קטן (שגיאה, "שולח") | 150–200ms |
| כניסה של סקשן                 | 200–300ms |

- **אף פעם מעל 300ms.** תנועה ארוכה יותר מרגישה כמו המתנה.
- **האטה בסוף (ease-out):** מתחיל מהר ונעצר בעדינות. ב-Tailwind `ease-out`, או עקומה רכה יותר: `cubic-bezier(0.22, 1, 0.36, 1)`.
- **בלי קפיצה ובלי חריגה מהיעד.** לא bounce, לא spring שעובר את הנקודה וחוזר. בעקומת `cubic-bezier` המספר השני והרביעי נשארים בין 0 ל-1. מספר מעל 1 (כמו `1.56`) יוצר חריגה.
- **מרחק קטן: 8–16px.** סקשן עולה 12px תוך כדי שהוא מופיע. לא עף מהצד.
- **כיוון:** תנועה אנכית עדיפה. אם משהו נכנס מהצד, הוא נכנס מימין (צד ההתחלה בעברית).
- **מזיזים רק `opacity` ו-`transform`/`translate`.** לא `height`, `width`, `top` או `margin`, כי הם מזיזים את כל מה שמתחת.
- **הדרגה בין פריטים** (כרטיס אחרי כרטיס): עד 50ms בין פריט לפריט, ועד 4 פריטים. אחרי זה כל השאר נכנסים יחד.
- **פעם אחת.** סקשן שנכנס לא נכנס שוב כשגוללים למעלה ולמטה.

## 3. נגישות: שני מתגים, תמיד

יש שתי דרכים שבהן גולש אומר "בלי תנועה", וכל תנועה בדף מכבדת את שתיהן:

1. **הגדרה של מערכת ההפעלה:** `prefers-reduced-motion: reduce`. `globals.css` של התבנית כבר מקצר לאפס כל `animation` ו-`transition` כשההגדרה פעילה.
2. **"עצירת אנימציות" בכפתור הנגישות** של התבנית (`AccessibilityWidget`). לפי התוכנית של התבנית, כל מצב של הכפתור הוא class על `<html>`, ומוגדר ב-`globals.css`.

**את השם המדויק של ה-class לא מנחשים.** מוצאים אותו בקוד:

```bash
grep -n "classList\|className" site/components/AccessibilityWidget.tsx
grep -n "html\." site/app/globals.css
```

בדוגמאות כאן הוא מופיע כ-`STOP_CLASS`. מחליפים בשם האמיתי בכל מקום. אין עדיין `AccessibilityWidget.tsx` בעותק של האתר? כותבים רק את התנאי של `prefers-reduced-motion`, ורושמים ב-`3-design/design.md` תחת "פתוח".

### מה זה אומר בפועל

- **`motion-safe:` של Tailwind לא מספיק.** הוא רואה רק את הגדרת המערכת, לא את כפתור הנגישות. מגדירים פעם אחת ב-`globals.css` וריאנט משלנו שבודק את שניהם:

```css
@custom-variant motion-ok {
  @media (prefers-reduced-motion: no-preference) {
    html:not(.STOP_CLASS) & {
      @slot;
    }
  }
}
```

ואז כותבים `motion-ok:transition motion-ok:duration-150` במקום `transition duration-150`. (הצורה הזו נבדקה בבנייה על התבנית.)

- **JavaScript שמזיז משהו** בודק את שניהם לפני שהוא רץ:

```ts
const noMotion =
  window.matchMedia("(prefers-reduced-motion: reduce)").matches ||
  document.documentElement.classList.contains("STOP_CLASS");
```

- **`ScrollToFormButton`** בתבנית בודק היום רק את הגדרת המערכת. אם יש בעותק כפתור נגישות, מוסיפים לבדיקה שלו גם את ה-class, כדי שהגלילה לטופס תהיה מיידית גם למי שעצר אנימציות מהכפתור.
- **התוכן גלוי תמיד.** בלי JavaScript, עם תנועה כבויה, או אם משהו נכשל, כל הטקסט מופיע. מצב "מוסתר עד שנכנס" חל רק כשתנועה מותרת ורק אחרי שהסקריפט רץ.

## 4. מה אף פעם לא זז

- **הטופס.** לא נכנס באנימציה, לא רועד בשגיאה, לא משנה גובה כשהודעת שגיאה מופיעה (התבנית כבר שומרת מקום להודעות). שגיאה מסומנת בטקסט ובצבע.
- **ה-CTA.** נשאר במקום שלו. משוב בכפתור הוא שינוי צבע, צל, או לחיצה קטנה (`active:scale-[0.98]`). כפתור לא קופץ, לא זז הצידה ולא מופיע ונעלם תוך כדי גלילה.
- **טקסט בזמן קריאה.** לא נע, לא מתחלף לבד, לא נדחף על ידי תמונה שנטענת מאוחר (לכן `width`/`height` לכל תמונה).
- **הפתיחה (מה שרואים בלי לגלול).** לא נכנסת באנימציה. טקסט שמתחיל שקוף מאחר את הרגע שבו הדף נחשב "מוכן", וזה פוגע במהירות שגוגל ומטא מודדים. היא פשוט שם מההתחלה.

## 5. כלים

**קודם CSS.** כמעט כל מה שמותר בסעיף 1 נעשה ב-Tailwind ובכמה שורות ב-`globals.css`.

כניסה של סקשנים בגלילה: מסמנים סקשן ב-`data-reveal`, ושמים בדף פעם אחת את הרכיב הזה (`site/components/RevealOnScroll.tsx`):

```tsx
"use client";

import { useEffect } from "react";

/*
 * כניסה עדינה של סקשנים בגלילה. מסמנים סקשן ב-data-reveal.
 * בלי JS, או כשתנועה כבויה, הכול גלוי מההתחלה. ה-CSS ב-globals.css.
 */
export function RevealOnScroll() {
  useEffect(() => {
    const els = [...document.querySelectorAll<HTMLElement>("[data-reveal]")];
    if (els.length === 0 || !("IntersectionObserver" in window)) return;
    // מה שכבר על המסך לא מסתתר ולא "נכנס" שוב
    for (const el of els)
      if (el.getBoundingClientRect().top < window.innerHeight)
        el.classList.add("is-in");
    document.documentElement.classList.add("js-reveal");
    const io = new IntersectionObserver(
      (entries) => {
        for (const e of entries)
          if (e.isIntersecting) {
            e.target.classList.add("is-in");
            io.unobserve(e.target);
          }
      },
      { rootMargin: "0px 0px -10% 0px" },
    );
    for (const el of els) if (!el.classList.contains("is-in")) io.observe(el);
    return () => io.disconnect();
  }, []);
  return null;
}
```

וב-`globals.css`:

```css
@media (prefers-reduced-motion: no-preference) {
  html.js-reveal:not(.STOP_CLASS) [data-reveal] {
    transition:
      opacity 260ms cubic-bezier(0.22, 1, 0.36, 1),
      translate 260ms cubic-bezier(0.22, 1, 0.36, 1);
  }
  html.js-reveal:not(.STOP_CLASS) [data-reveal]:not(.is-in) {
    opacity: 0;
    translate: 0 12px;
  }
}
```

- לא שמים `data-reveal` על הפתיחה ולא על הסקשן של הטופס.
- גולש שמפעיל "עצירת אנימציות" באמצע הגלילה: התנאי `:not(.STOP_CLASS)` מפסיק להתקיים, וכל מה שעוד לא נכנס מופיע מיד.
- הרכיב והסגנון נבדקו בבנייה על התבנית (עם שם class לדוגמה).

**ספריית אנימציה ב-JavaScript** (כמו motion או GSAP) רק אם CSS באמת לא יכול. לפני שמוסיפים, עונים על כל השאלות, ורושמים את התשובות ב-`3-design/design.md`:

1. מה בדיוק אי אפשר לעשות ב-CSS? (אם התשובה היא "יהיה יותר נוח", לא מוסיפים.)
2. כמה היא מוסיפה למשקל הדף בטלפון, ומה זה עושה ל-2.5 השניות של הפתיחה?
3. מה הרישיון שלה, ומותר להשתמש בה באתר מסחרי?
4. היא מכבדת את שני המתגים מסעיף 3? (רוב הספריות רואות רק את הגדרת המערכת. את ה-class של כפתור הנגישות צריך לחבר ידנית.)
5. בעל העסק אישר להוסיף חבילה, והגרסה נעולה ב-`package.json` (בלי `^`).

**אם הסקיל `emil-design-eng` מותקן** (`~/.claude/skills/emil-design-eng`), אפשר להיעזר בו לגבי עקומות, משכים ותחושה של תנועה. כשהוא סותר את הקובץ הזה בעניין נגישות, עברית או מה שאסור להזיז, הקובץ הזה קובע.
