# חיבור דומיין לדף: איפה לוחצים אצל כל ספק

הקובץ הזה משמש את `/page-live`. הוא אומר לקלוד מה להסביר לבעל העסק, צעד אחרי צעד, כדי שהדף יעלה על כתובת של העסק.

## מה בודקים לפני הכול

| שאלה                    | למה                                                                                                   |
| ----------------------- | ----------------------------------------------------------------------------------------------------- |
| יש לעסק דומיין?         | אין → הקטע "אין דומיין" למטה. קלוד לא קונה דומיין ולא משלם                                            |
| איפה הדומיין רשום?      | שם מוסיפים את הרשומה. בדרך כלל זה האתר שבו קנו אותו ומשלמים עליו כל שנה                               |
| מי מנהל את ה-DNS בפועל? | לפעמים הדומיין רשום ב-Box, אבל ה-DNS עבר ל-Cloudflare או לחברת האחסון של האתר. הרשומה הולכת למי שמנהל |
| איזו כתובת רוצים לדף?   | ההמלצה: תת-דומיין, למשל `lp.mybiz.co.il` או `go.mybiz.co.il`. ראו "תת-דומיין או דומיין ראשי"          |

**איך יודעים מי מנהל את ה-DNS:** `dig +short NS mybiz.co.il` (במק ובלינוקס) או `nslookup -type=NS mybiz.co.il` (בווינדוס). התשובה היא שמות השרתים:

| מה מופיע בתשובה                        | מי מנהל                                                      |
| -------------------------------------- | ------------------------------------------------------------ |
| `...ns.cloudflare.com`                 | Cloudflare                                                   |
| `ns11.domaincontrol.com` וכדומה                | GoDaddy                                                      |
| `dns1.registrar-servers.com` וכדומה    | Namecheap                                                    |
| `ns1.box.co.il` וכדומה                 | Box                                                          |
| `ns1.vercel-dns.com`                   | Vercel עצמו. אז מוסיפים רשומות ב-Vercel, לא אצל הספק         |
| שם של חברת אחסון (למשל של אתר וורדפרס) | חברת האחסון. נכנסים לממשק שלה ומחפשים "DNS" או "Zone Editor" |

## תת-דומיין או דומיין ראשי

- **תת-דומיין (ההמלצה):** `lp.mybiz.co.il`. רשומה אחת מסוג CNAME. האתר הקיים של העסק על `mybiz.co.il` ממשיך לעבוד כמו שהוא, וגם המיילים. זה הכי פשוט והכי בטוח.
- **דומיין ראשי:** `mybiz.co.il` עצמו. רק אם בעל העסק מבקש את זה במפורש, ורק אם אין עליו אתר אחר שעובד. צריך רשומת A (ולא CNAME), ובדרך כלל גם `www`. מה שהיה על הדומיין עד עכשיו מפסיק להופיע.

## הערכים של Vercel

**נבדק מול התיעוד של Vercel ב-1.11.26:**

- https://vercel.com/docs/domains/working-with-domains/add-a-domain (עודכן אצלם 16.9.26)
- https://vercel.com/docs/domains/set-up-custom-domain (עודכן אצלם 11.8.26)
- https://vercel.com/kb/guide/a-record-and-caa-with-vercel (עודכן אצלם 16.10.26)

| מה                                   | סוג רשומה | שם (Name / Host)                        | ערך (Value / Target / Points to)                                                                                       |
| ------------------------------------ | --------- | --------------------------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| תת-דומיין, למשל `lp.mybiz.co.il`     | CNAME     | `lp` (רק החלק שלפני הדומיין)            | **הערך הייחודי שהפרויקט מקבל.** נראה בערך כך: `d1d4fc829fe7bc7c.vercel-dns-017.com`. מעתיקים מ-Vercel, לא מכאן         |
| דומיין ראשי `mybiz.co.il`            | A         | `@` (או ריק, לפי הספק)                  | **הכתובת ש-Vercel מציג לפרויקט.** הכללית היא `76.76.21.21`, ויש פרויקטים חדשים שמקבלים כתובת אחרת, למשל `216.198.79.1` |
| הדומיין כבר בשימוש בחשבון Vercel אחר | TXT       | `_vercel` (כלומר `_vercel.mybiz.co.il`) | המחרוזת ש-Vercel מציג. מופיעה רק אם Vercel מבקש אימות בעלות                                                            |

**הכלל: לא מעתיקים ערך מהקובץ הזה.** כל פרויקט מקבל ערכים משלו. את הערכים לוקחים מאחד משני מקומות:

1. הפקודה `npx vercel@latest domains verify '<הדומיין>' --project '<שם הפרויקט>'` מתוך התיקייה `site/`. היא מדפיסה מה חסר ומה הערך הנכון.
2. בדשבורד של Vercel: הפרויקט ← **Settings** ← **Domains** ← הכרטיס של הדומיין. שם כתובים סוג הרשומה, השם והערך.

**CAA:** אם יש לדומיין רשומת CAA (נדיר אצל עסקים קטנים), היא צריכה להרשות ל-Let's Encrypt להנפיק תעודה, אחרת המנעול לא יופיע. בודקים: `dig +short CAA mybiz.co.il`. תשובה ריקה = אין בעיה.

## איפה מוסיפים רשומה אצל כל ספק

בכל ספק, הרשומה כוללת שלושה דברים: **סוג** (CNAME או TXT), **שם** (החלק שלפני הדומיין), **ערך** (מה ש-Vercel או גוגל נתנו). אם יש שדה TTL, משאירים את ברירת המחדל או בוחרים את הנמוך ביותר.

### Box (box.co.il)

**לא אומת.** אתר התמיכה של Box (support.box.co.il) חסם קריאה אוטומטית ב-1.11.26 (שגיאה 403), ולא נמצא מדריך ציבורי שלהם להוספת רשומות. מה שכן אומת: Box הוא רשם ישראלי מוסמך, והכניסה לניהול הדומיינים היא בכתובת https://domains.box.co.il/user/login.

מה לומר לבעל העסק:

1. נכנסים ל-https://domains.box.co.il/user/login עם המשתמש של Box.
2. בוחרים את הדומיין, ומחפשים אזור בשם "ניהול DNS", "רשומות DNS" או "Zone".
3. מוסיפים רשומה חדשה: סוג, שם וערך כמו בטבלה למעלה.
4. לא מוצאים את האזור? שולחים לי צילום מסך של מסך ניהול הדומיין, ואגיד בדיוק על מה ללחוץ. אפשר גם לפתוח פנייה לתמיכה של Box (https://support.box.co.il/hc/he/requests/new) ולכתוב: "אני צריך להוסיף רשומת CNAME לתת-דומיין lp עם הערך ...".

אם `dig +short NS` מראה ש-DNS לא מנוהל ב-Box (למשל Cloudflare), Box לא רלוונטי. הולכים לספק שמנהל.

### GoDaddy

**אומת ב-1.11.26** מול https://www.godaddy.com/help/add-a-cname-record-19236 (בלי תאריך עדכון בדף).

1. נכנסים ל-GoDaddy ופותחים את **Domain Portfolio**.
2. לוחצים על הדומיין. נפתח עמוד **Domain Settings**.
3. עוברים ללשונית **DNS**.
4. לוחצים **Add New Record** ובוחרים בשדה **Type** את `CNAME` (או `TXT`).
5. **Name:** רק החלק שלפני הדומיין, למשל `lp`. לא `@` ולא הכתובת המלאה.
6. **Value:** הערך מ-Vercel.
7. **TTL:** משאירים (ברירת המחדל שעה).
8. **Save**. אם מוגדרת אצלם הגנת דומיין, GoDaddy יבקש קוד אימות שנשלח לטלפון או למייל.

לפי GoDaddy: בדרך כלל השינוי נכנס תוך שעה, ולפעמים עד 48 שעות.

### Namecheap

**אומת ב-1.11.26** מול https://www.namecheap.com/support/knowledgebase/article.aspx/9646/2237/how-to-create-a-cname-record-for-your-domain/ (עודכן אצלם 23.9.24).

1. נכנסים ל-Namecheap ← בתפריט הצד **Domain List** ← **Manage** ליד הדומיין.
2. לשונית **Advanced DNS** ← באזור **Host Records** לוחצים **Add New Record**.
3. בוחרים **CNAME Record** (או **TXT Record**).
4. **Host:** `lp`. **Value:** הערך מ-Vercel. **TTL:** הנמוך ביותר שיש.
5. לוחצים על ה-✓ או **Save All Changes**.

לפי Namecheap, אפשר להוסיף רשומות שם רק אם הדומיין משתמש ב-BasicDNS, PremiumDNS או FreeDNS שלהם. אם הוא מחובר לאחסון של Namecheap, מוסיפים ב-cPanel של האחסון.

### Cloudflare

**אומת חלקית ב-1.11.26** מול https://developers.cloudflare.com/dns/manage-dns-records/how-to/create-dns-records/ (עודכן אצלם 6.5.26) ו-https://developers.cloudflare.com/dns/proxy-status/ (עודכן אצלם 21.4.26). התיעוד מתאר את הכפתורים, אבל לא את שמות כל השדות.

1. נכנסים ל-Cloudflare ← בוחרים את הדומיין ← עמוד **DNS Records** (בתפריט: DNS ← Records).
2. **Add record**.
3. **Type:** `CNAME` (או `TXT`). **Name:** `lp`. **Target** (או **Content**): הערך מ-Vercel.
4. **Proxy status:** להעביר ל-**DNS only** (ענן אפור). **לא Proxied (ענן כתום).**
5. **Save**.

**למה DNS only:** Vercel ממליץ להתחבר ישירות, בלי פרוקסי באמצע (https://vercel.com/kb/guide/can-i-use-a-proxy-on-top-of-my-vercel-deployment, עודכן אצלם 19.10.26). עם ענן כתום Vercel לא תמיד רואה את הרשומה, התעודה יכולה להיתקע, ובמצב SSL מסוים (Flexible) הדף נכנס ללולאה של הפניות.

ב-Cloudflare השינוי נכנס בדרך כלל תוך דקות.

### ספק אחר (חברת אחסון, LiveDNS, Domain The Net, Wix, וכו')

**לא אומת לכל ספק בנפרד.** ההנחיה הכללית:

1. נכנסים לאזור האישי אצל מי שמנהל את ה-DNS (ראו "איך יודעים מי מנהל").
2. מחפשים: "DNS", "ניהול DNS", "Zone Editor", "DNS Records", "Advanced DNS".
3. מוסיפים רשומה: סוג, שם (`lp`), ערך.
4. אם יש שדה TTL, משאירים או בוחרים את הנמוך ביותר.
5. לא מוצאים → בעל העסק שולח צילום מסך, וקלוד מסביר על מה ללחוץ לפי מה שבתמונה. לא מנחשים שמות של כפתורים.

**שדה השם אצל ספקים שונים:** רוב הספקים רוצים רק `lp`. יש ספקים שרוצים את השם המלא, `lp.mybiz.co.il`, ויש שמוסיפים את הדומיין לבד. אם אחרי השמירה הרשומה מופיעה כ-`lp.mybiz.co.il.mybiz.co.il`, מוחקים ויוצרים מחדש עם `lp` בלבד.

## רשומת TXT לגוגל (Search Console)

**אומת ב-1.11.26** מול https://support.google.com/webmasters/answer/9008080.

- **סוג:** TXT. **שם:** `@` או ריק (הדומיין הראשי, לא `lp`). **ערך:** המחרוזת שגוגל נותן, מתחילה ב-`google-site-verification=`.
- הרשומה מאמתת את כל הדומיין, כולל כל תתי-הדומיינים. אם בעל העסק כבר אימת את `mybiz.co.il` ב-Search Console כ"דומיין" (Domain property), לא צריך עוד רשומה: `lp.mybiz.co.il` כבר בפנים.
- **לא מוחקים אותה אחרי האימות.** בלעדיה גוגל מבטל את האימות.
- יכולה כבר להיות רשומת TXT אחרת על `@` (למשל של המייל). זה בסדר. מוסיפים רשומה חדשה ולא עורכים את הקיימת.
- גוגל אומר שזה יכול לקחת עד יומיים-שלושה. בפועל בדרך כלל מהר יותר.

## כמה זמן לוקח

| מה                                    | בדרך כלל       | הכי הרבה            |
| ------------------------------------- | -------------- | ------------------- |
| CNAME ב-Cloudflare                    | דקות           | שעה                 |
| CNAME ב-GoDaddy / Namecheap / Box     | 15 דקות עד שעה | 48 שעות             |
| המנעול (תעודת SSL) אחרי שהרשומה נכנסה | כמה דקות       | שעה                 |
| TXT לגוגל                             | שעה            | 2–3 ימים (לפי גוגל) |

אם הרשומה כבר הייתה קיימת עם ערך אחר, הישן יכול להישאר בזיכרון של האינטרנט עד שעות (לפי ה-TTL הישן).

## איך בודקים שזה עובד

מהתיקייה של האתר או מכל מקום:

```bash
dig +short CNAME lp.mybiz.co.il            # צריך להחזיר את הערך מ-Vercel
dig +short lp.mybiz.co.il @1.1.1.1          # צריך להחזיר כתובות (לא ריק)
dig +short TXT mybiz.co.il                  # לגוגל: צריך להופיע google-site-verification=...
```

בווינדוס, בלי dig:

```bash
nslookup -type=CNAME lp.mybiz.co.il 1.1.1.1
nslookup -type=TXT mybiz.co.il 1.1.1.1
```

ואחר כך Vercel עצמו:

```bash
npx vercel@latest domains verify 'lp.mybiz.co.il' --project '<שם הפרויקט>'
```

הפקודה יוצאת בקוד 0 כשהכול תקין, ובקוד אחר עם הסבר מה לתקן. `@1.1.1.1` שואל את השרת של Cloudflare ישירות, כדי לא לקבל תשובה ישנה מהמחשב.

| הכתובת עולה בלי מנעול, או "Not secure"                        | התעודה עוד לא הונפקה, או CAA שחוסם                                               | לחכות עשר דקות. אחרי שעה: `dig +short CAA` ולבדוק ש-Let's Encrypt מורשה                        |

## אין דומיין

קלוד לא קונה דומיין ולא נכנס לחשבון תשלום. מסבירים לבעל העסק:

1. שם: קצר, בלי מקפים אם אפשר, `.co.il` לעסק ישראלי.
2. קונים אצל רשם מוסמך, למשל Box (https://www.box.co.il/buy-domain/), או GoDaddy / Namecheap ל-`.com`. המחיר והתנאים באתר שלהם. בעל העסק משלם בעצמו.
3. אחרי הקנייה ממשיכים מ"איפה מוסיפים רשומה" עם תת-דומיין, או עם הדומיין הראשי אם אין עליו שום דבר אחר.

עד שיש דומיין, הדף יכול לעבוד על הכתובת של Vercel (`<שם הפרויקט>.vercel.app`). אפשר להמשיך לחיבורים, ולחבר דומיין אחר כך עם `/page-live`.
